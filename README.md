## Overview

The **kirby-fitzpatrick-fleeting-bug-ingestion** skill transforms cognitive writing science into deterministic rules for AI coding assistants, code reviews, and system documentation.

## Quick Installation & Universal Setup

Add this skill directly to your coding assistant by pasting the **Magic Prompt** below into your agent chat:

```markdown
@agent Install the "kirby-fitzpatrick-fleeting-bug-ingestion" skill:
1. Ensure ~/.gemini/config/skills, ~/.cursor/skills, ~/.cursor/skills-cursor, ~/.codeium/windsurf/skills, ~/.grok/skills, ~/.kimi-code/skills, and ~/.reasonix/skills exist.
2. Clone https://github.com/markkirby125/kirby-fitzpatrick-fleeting-bug-ingestion.git to ~/.agents/skills/kirby-fitzpatrick-fleeting-bug-ingestion.
3. Symlink ~/.agents/skills/kirby-fitzpatrick-fleeting-bug-ingestion to all local AI app skill directories.
```

## Core Patterns

- **Fleeting Bug Ingestion**: Fleeting Bug Ledger: capture transient bugs instantly under `BUG-YYYYMMDD-HHMMSS` with exact reproduction steps.
- **Practical Application**: Structured incident logs and reproducible issue reporting.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
